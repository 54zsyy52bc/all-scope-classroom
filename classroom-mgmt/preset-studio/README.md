# Preset Studio · 预设编辑器（办公电脑独立应用）

课堂管理系统 v4 的**预设生产端**：安装在教师办公电脑上，创建/编辑/管理班级与活动预设，
通过 `.kctpreset` 预设包把数据传递到教室大屏使用。

> 设计背景见 `课堂管理系统开发文档/08_预设编辑器独立化方案.md`。
> 本应用**完全离线**：不连 broker、不起 HTTP 服务、不依赖教室环境。教室端只做接收与使用。

## 功能

| 模块 | 能力 |
|------|------|
| 班级预设 | 名称 / 座位数 / 分组大小 / 备注 的创建、编辑、删除 |
| 活动预设 | 名称 / 分类 / 备注 + **器材清单**（eqId/eqName/分类/默认数量）+ **任务模板** + **默认计时**（timed/时长） |
| 器材字典 | 常用器材维护（eqId/名称/分类），编辑活动时对照选用 |
| 预设包导出 | 全量导出 `.kctpreset`（U盘/网盘/微信带到教室） |
| 预设包导入 | 选文件 → **预演**（新增 N / 覆盖 M / 跳过 K，逐条明细）→ 确认合并；也可回迁他人/教室备份继续编辑 |

## 启动

```bash
npm install
npm start        # Electron 窗口打开
# 打包 Windows 便携版：npm run pack → dist/PresetStudio.exe（可复制到办公电脑免安装运行）
```

数据落本机 `%APPDATA%/PresetStudio/presets.json`。多台办公电脑各自维护，靠 `.kctpreset` 文件同步。

## 预设包流转（办公端 → 教室端）

1. Studio 编辑好班级/活动预设 →「导出预设包」→ 得到 `预设备份_YYYYMMDD_HHmm.kctpreset`
2. U盘/网盘带到教室 → 大屏「预设管理 → 导入预设包」→ 查看预演结果（新增/覆盖/跳过）→「确认导入」
3. 大屏「开始上课 / 发布活动」下拉即可选用
4. 反向备份：大屏「导出备份」→ 文件带回家 → Studio「导入预设包」继续编辑

**合并规则**：按 `presetId`（跨机器稳定）比对 `updatedAt` —— 包内较新则覆盖、本地较新则跳过
（保护教室现场修改不被旧文件覆盖）。包格式由 `shared/preset-package.js` 协议约束，双端共用同一校验。

## 与旧 Web 编辑器的关系

v4 之前预设编辑是教师端服务内置的 Web 页面（`teacher/public/editor/` + Electron 壳），
v4 已按决策迁出为独立应用并删除旧目录——**编辑入口唯一化**，教室大屏回归纯"接收与使用"。
UI 复用了旧编辑器的班级/活动表单与器材/模板行编辑器，数据层改为本地库 + IPC。
