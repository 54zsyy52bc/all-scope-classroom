🌿 绿网使用帮助

课堂上要用的物联网工具，都在这一个浏览器里。

🧑‍🎓 学生怎么用

  1. 打开绿网就停在导航首页，点卡片就能进对应的学习网站。
  2. 要连设备时，点工具栏的 「本机 IP」，把上面的大号地址填到设备程序里。
  3. 要用物联网服务时，点工具栏的 「SIoT 控制台」，服务没启动它会告诉你步骤。
  4. 标签页最多同时开 8 个；关掉最后一个会自动回到首页，不会把浏览器关没了。
  5. 看到"这个网页被老师屏蔽了"是正常的，回首页换个网站就好。

👩‍🏫 老师怎么管

  1. 按 Ctrl + Shift + A（或点工具栏最右边的 🔒），输入管理口令进入管理页。
  2. 屏蔽名单：支持 4 种规则 —— 域名、关键词、网址前缀、正则；还有"白名单例外"用来放行必用站点。
  3. 也可以切成"只允许白名单"模式：除了例外清单里的站点，其它一律打不开。
  4. 导航内容：新增/删除分组和网站卡片，改完点保存，学生端刷新首页立即生效。
  5. 系统设置：SIoT 地址端口、全域联动开关、是否允许下载。
  6. 管理口令连续输错 3 次会锁定 60 秒，防止学生在课上试密码。

⌨️ 快捷键

按键作用
Ctrl + T新标签页
Ctrl + W关闭当前标签
Ctrl + L定位到地址栏
Ctrl + R / F5刷新
Alt + ← / →后退 / 前进
Ctrl + Shift + A打开教师管理

🔗 和"全域"课堂系统的关系

绿网是由「全域学生桌面」拉起的课程应用之一。老师在大屏上发布活动、打开或关闭锁定策略时， 绿网会同步显示当前活动与倒计时；策略为"锁定"时，绿网会锁住上网功能， 等老师发布下一个活动再自动解锁。
