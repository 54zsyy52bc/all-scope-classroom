    怎么用这个地址？

    1. 在本机双击 start SIoT.bat 启动物联网服务（首次运行要允许网络访问）。
    2. 设备（行空板等）连的是同一个 Wi-Fi / 同一个交换机，否则填了也连不上。
    3. 在设备的程序里把「服务器地址 / MQTT 主机」填成上面给出的那个地址，端口用 1883（WebSocket 用 1888）。
    4. 如果这里显示的是 169.254.x.x，说明没拿到路由器分配的地址，请重新插网线或重连 Wi-Fi。
