## 0. 五模块一句话

| 模块 | 职责 |
|------|------|
| **预设管理** | 在**独立编辑器**中分别维护班级预设（班名/座位数/分组）与活动预设（器材清单/任务模板/**默认计时**）；配置完成后大屏「开始上课 / 发布活动」时**导入**（下拉加载）使用 |
| **上课流程** | 大屏点「上课」→ 选择已导入的班级预设 + 课堂活动预设 → 进入授课模式（checkin 登记） |
| **活动发布** | 授课期间发布**预设活动**（一键）或**现场自定义活动**（临时填写）→ 广播到学生端 |
| **计时功能** | 活动可启用内置计时器：暂停 / 调整时长 / 重新计时；**截止自动提醒师生双方**；发布时可选是否启用 |
| **权限控制** | 教师设置学生端使用策略：**仅在活动进行期间允许操作，非活动时间自动锁定** |

## 1. 领域模型：活动 = 任务 + 计时元数据（复用 t_task）

不新造"活动"表，而是把 **t_task 升级为活动**：任务即活动的一种（未启用计时 = 普通任务），
保证与 v2 的 task.status 上报协议、报表、状态墙**完全兼容**。

### 1.1 t_task 扩展列

| 列 | 类型 | 说明 |
|----|------|------|
| `source` | TEXT | `preset`（来自活动预设）/ `custom`（现场自定义） |
| `activity_preset_id` | TEXT | source=preset 时关联的活动预设 |
| `timed` | INTEGER | 是否启用计时（0/1） |
| `duration_sec` | INTEGER | 计时总时长（秒） |
| `timer_state` | TEXT | `idle`（未计时）/ `running` / `paused` / `expired` / `closed` |
| `timer_started_at` | INTEGER | 最近一次 start/restart 的时刻（ms） |
| `timer_paused_at` | INTEGER | 最近一次 pause 的时刻（ms） |
| `timer_remaining_ms` | INTEGER | paused/expired 时的剩余毫秒（running 时动态计算） |

### 1.2 活动预设（t_activity_preset）扩展

| 列 | 说明 |
|----|------|
| `timed` | INTEGER 该预设默认启用计时（0/1） |
| `duration_sec` | INTEGER 默认时长（秒，发布时可在弹窗改） |

> 旧库迁移：`_migrate()` 补列；旧数据 timed=0（不启用），行为与 v2 完全一致。

## 2. 活动生命周期状态机（教师端权威计时）

```
                发布(启用计时)            发布(未启用计时)
   idle ──────→ running ────────────→ closed(教师关闭/下课)
     │            │  ▲                    ▲
     │            │  └── resume(继续)      │
     │            ▼        ┌──────────────┘
     │         paused ─────┘
     │            │
     │            └─────→ expired(截止) ──→ closed
     │                      ▲
     │                      │
     └──→ running ←─ adjust(调时长) / restart(重新计时)
```

- **idle**：活动已创建未发布 / 未开始计时
- **running**：计时进行中（`剩余 = duration - (now - startedAt)`，教师端权威计算）
- **paused**：暂停（`剩余`固化到 `timer_remaining_ms`）
- **expired**：剩余归零（**师生双方提醒**后仍可 restart / adjust 继续，直至教师关闭）
- **closed**：教师手动结束或下课/关闭会话，学生端计时器消失

### 2.1 计时器状态机（单活动内部）

```
         start            pause            resume
   idle ──────→ running ──────→ paused ──────→ running
                 │  ▲            │
                 │  └──── restart/continue ────┘
                 │
                 ├── adjust(durationSec) → running（按新时长重算剩余）
                 ├── expire(自然到期) → expired（发提醒）→ 可 restart/adjust
                 └── stop → closed
```

### 2.2 截止检测（教师端）

- 每个 running 活动注册一个**独立定时器**（setTimeout 到剩余时长；500ms 粒度轮询剩余做 SSE 推送）。
- 到期动作（**顺序固定**）：
  1. `t_task.timer_state = 'expired'`，`timer_remaining_ms = 0`（写库）
  2. SSE `activity.timer {taskId, state:'expired', remainingMs:0}`（**教师端提醒**：大屏弹截止条 + 事件流）
  3. MQTT `cmd task_timer {taskId, action:'expired'}` 广播（**学生端提醒**：toast + 提示音）
  4. 重算锁定策略（见 §4）：strict 模式下该活动截止 → 若没有其他 running 活动 → 下发 `policy locked=true`

## 3. 模块联动逻辑（触发点 → 动作链）

### 3.1 预设管理（编辑器）→ 大屏导入

```
编辑器（独立应用）                        大屏 / 上课
  班级预设 CRUD ──────────┐
                         ├→ SQLite 单库（teacher 服务）
  活动预设 CRUD（器材/模板/默认计时）──┘        │
                                              ▼
                          大屏「开始上课」弹窗 = 预设下拉导入
                          大屏「发布活动」弹窗 = 活动预设下拉导入
```

- 编辑器维护的预设，大屏**无需二次配置**，下拉即用（数据同库）。
- 活动预设导入大屏后：显示器材件数、任务模板数、默认计时；发布时可改时长。

### 3.2 上课流程（大屏）

```
点「上课」→ 弹窗：教师名 + 班级预设(下拉) + 活动预设(下拉，可空)
  ├─ 班级预设 → 班级名/座位数/分组 自动填充
  ├─ 活动预设 → 器材清单注册 t_equipment + cmd equipment 广播（学生端登记页器材随活动）
  └─ 阶段 waiting → checkin
       ├─ cmd start 广播
       ├─ cmd policy 下发（模式按教师设置：open→unlock；activity→checkin 阶段不锁）
       └─ SSE phase.changed
```

### 3.3 活动发布（大屏 / 编辑器）

```
发布活动（两个来源）
  A. 预设活动：选活动预设 → 自动带出 标题/说明/器材/任务模板/默认计时
  B. 自定义活动：现场填写 标题/说明 + 可选计时开关/时长
        │
        ├─ t_task 落库（source=preset|custom，timed/duration）
        ├─ 阶段 checkin → task（自动推进）
        ├─ cmd task {taskId,title,desc,timed,durationSec,timerState:'running',remainingMs} 广播
        ├─ 启用计时 → 注册截止定时器 + SSE activity.timer{running}
        └─ 重算锁定策略：activity 模式 → 有 running 活动 → 下发 policy locked=false（解锁）
```

### 3.4 计时控制（大屏 / 编辑器 → 师生）

```
大屏活动条按钮            REST                     MQTT 广播              学生端
 暂停 ──→ POST timer{pause} ──→ cmd task_timer{pause,remainingMs} ──→ 计时器灰显暂停
 继续 ──→ POST timer{resume} ──→ cmd task_timer{resume,remainingMs} ──→ 恢复倒数
 调时长─→ POST timer{adjust,durationSec}→ cmd task_timer{adjust,durationSec} ──→ 按新时长倒数
 重计时─→ POST timer{restart} ──→ cmd task_timer{restart,remainingMs} ──→ 归零重数
 截止  ──（教师端定时器自动）──→ SSE activity.timer{expired} ──大屏弹截止条──┐
                              └─ cmd task_timer{expired} ──→ 学生端提醒 ──┘
```

### 3.5 权限控制（锁定策略）

```
教师设置策略（上课时或随时）：
  POST /sessions/:sid/policy {mode: open | activity}
        │
        ▼
教师端「策略引擎」在以下时机重算 → 下发 cmd policy {mode, locked, reason, phase}
  ├─ 上课开始
  ├─ 阶段变更（checkin/task/return/closed）
  ├─ 活动发布（task 阶段出现 running 活动）
  └─ 活动截止 / 活动关闭 / 下课
        │
        ▼
学生端：locked=true → 全屏锁定遮罩（拦截输入，心跳保持）
        locked=false → 关闭遮罩，恢复正常操作
```

**activity 模式的锁定判定表**（"非活动时间自动锁定"）：

| 阶段 | 有 running 活动？ | 锁定 | 理由 |
|------|------------------|------|------|
| checkin | — | 否 | 登记是课前必备流程 |
| task | 是 | 否 | 学生在做活动 |
| task | 否 | **是** | 教师讲解/等待间隙，防学生乱动 |
| return | — | 否 | 归还确认是课后必备流程 |
| waiting/closed | — | 否 | 未上课/已结束 |

> 诚实边界：锁定为 **Electron 软锁**（渲染层全屏遮罩 + 输入拦截 + 窗口置前），
> 非操作系统级硬锁（如 Windows 组策略锁屏）。软锁足够防"非活动时间乱操作"，
> 但防不了拔网线/重启等物理操作——系统级硬锁列为后续增强。

## 4. 状态流转规则（可执行判定）

### 4.1 活动状态流转（服务端 enforce）

| 前置状态 | 事件 | 后置状态 | 校验 |
|----------|------|----------|------|
| idle | 发布（timed=true） | running | 会话未 closed；timer_started_at=now |
| idle | 发布（timed=false） | closed（无计时） | 不注册定时器 |
| running | pause | paused | remaining=now 固化 |
| paused | resume | running | 以固化 remaining 重新倒数 |
| running/paused | adjust(d) | running | 按新时长重算（d>0） |
| running/paused/expired | restart | running | remaining=duration，started_at=now |
| running | 自然到期 | expired | 发双方提醒 + 策略重算 |
| expired/paused/running | stop/close | closed | 学生端移除计时器 |
| 任意 | 下课/会话关闭 | closed | 清理定时器 |

### 4.2 锁定策略流转（服务端 enforce）

| 触发 | 计算 | 下发 |
|------|------|------|
| 上课（waiting→checkin） | mode=open→false；activity→false（checkin 不锁） | cmd policy |
| checkin→task（发布活动） | 有 running 活动→false | cmd policy（解锁） |
| 活动截止/关闭，phase=task | 无 running 活动→**true** | cmd policy（锁定） |
| task→return | false（归还确认） | cmd policy（解锁） |
| return→closed | false | cmd policy |

### 4.3 会话阶段机（不变，新增钩子）

```
waiting → checkin → task ⇄（活动发布/截止触发策略重算）→ return → closed
```

## 5. 协议扩展清单（教师端 ↔ 学生端，Plan B 四主题）

### 5.1 下行 cmd（siot/ict_cmd，QoS1）

| action | payload | 说明 |
|--------|---------|------|
| `task`（扩展） | `{taskId,title,desc,source,timed,durationSec,timerState,remainingMs}` | 发布活动 |
| `task_timer`（新） | `{taskId, action:pause\|resume\|adjust\|restart\|expired, remainingMs?, durationSec?}` | 计时控制/截止 |
| `policy`（新） | `{mode:open\|activity, locked, reason, phase}` | 锁定策略 |

### 5.2 同步 sync（siot/ict_sync，hello 应答）

- `currentTask` 增加 `{timed, durationSec, timerState, remainingMs}`（迟到/重连恢复计时显示）
- 新增 `policy: {mode, locked}`（迟到/重连恢复锁定状态）

### 5.3 SSE 事件（教师端 → 大屏）

| 事件 | payload | 触发 |
|------|---------|------|
| `activity.timer`（新） | `{taskId, state:running\|paused\|expired, remainingMs}` | 计时变更/截止 |
| `policy.changed`（新） | `{mode, locked, reason, phase}` | 策略重算 |
| `task.published`（已有） | 含计时字段 | 发布活动 |

### 5.4 REST 扩展（教师端 HTTP）

| 端点 | 说明 |
|------|------|
| `POST /sessions/:sid/activities` | 发布活动（source=preset\|custom；activityPresetId；timed；durationSec）——兼容旧 `/tasks` 语义 |
| `POST /sessions/:sid/activities/:taskId/timer` | `{action:start\|pause\|resume\|adjust\|restart\|stop, durationSec?}` |

| `POST /sessions/:sid/policy` | `{mode:open\|activity}` 设置学生端使用策略 |
| `GET /sessions/:sid/policy` | 当前策略 |
| `GET /presets/activities/:id` | 已存在；活动预设响应增加 timed/durationSec |

## 6. 学生端行为（渲染层）

| 状态 | 行为 |
|------|------|
| 收到 cmd task（timed=true, running） | 活动卡显示计时器（mm:ss 每秒递减）；按钮可点 |
| 收到 cmd task_timer{pause} | 计时器灰显"已暂停 mm:ss" |
| 收到 cmd task_timer{resume/adjust/restart} | 按新剩余/时长恢复倒数 |
| 收到 cmd task_timer{expired} | 计时器变红"已截止" + toast 提醒（+提示音） |
| 收到 cmd policy{locked:true} | **全屏锁定遮罩**（拦截点击/键盘；心跳与 MQTT 保持在线） |
| 收到 cmd policy{locked:false} | 关闭遮罩恢复操作 |
| hello→sync | currentTask 计时字段 + policy 恢复（迟到/重连） |

## 7. 关键联动场景（端到端闭环演示）

**场景：带计时的预设活动 + 活动模式锁定**

```
1. 编辑器：建活动预设「焊接入门」（器材 DEV-BOARD/LED，任务模板×2，默认计时 10 分钟）
2. 大屏：开始上课 → 选班级预设「初二(1)班」+ 活动预设「焊接入门」
   → 器材下发学生端；策略=activity，checkin 不锁
3. 学生登记 → 大屏发布「焊接入门」（计时 10:00 启动）
   → 阶段 task；cmd task 广播；cmd policy locked=false（解锁）
4. 学生做活动：计时器 10:00 → 9:59 ...（教师可暂停/调时长/重计时）
5. 10 分钟到 → 教师端判定 expired：
   → SSE 大屏弹「活动截止」；cmd task_timer{expired} 学生端提醒；
   → 策略重算：无 running 活动 → cmd policy locked=true（学生机锁定）
6. 教师讲解/点评 → 再次发布下一活动 → 解锁 → 循环
7. 下课 → return 阶段解锁归还 → 全部归还 → HMAC 关机
```
