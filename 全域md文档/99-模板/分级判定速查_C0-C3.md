# 分级判定速查 · C0~C3（改动风险分级）

> 完整规则见 [[审查标准总纲_v2.0]] §4~§5。开 PR 前用本卡 30 秒判级，标签写 `risk:C*`。

## 三步判定
1. **一票升档 C3**（命中任一条直接 C3）：shared 契约（topics/信封/preset-package）｜ 关机/HMAC/鉴权/CORS/绑定地址 ｜ DB schema 迁移含存量数据 ｜ 三端同时改动
2. **评分卡**（加总）：
   - diff 行：≤20→0 ｜ ≤150→1 ｜ ≤600→2 ｜ >600→C3
   - 文件数：≤1→0 ｜ ≤3→1 ｜ >3→2
   - 涉及端数：1→0 ｜ 2→2 ｜ 3→C3
   - **学生端可见文案/状态页/交互 → +2**（强制走交互成对 + UX）
   - 阶段机/计时/策略 或 新路由/SSE/新 action → +2
   - DB 加安全列 → +2 ｜ 教师端新操作入口 / 导出导入格式 / 术语布局 → +1
3. 映射：0→C0 ｜ 1→C1 ｜ ≥2→C2 ｜ 总分≥4→C3。**取高不取低**（降档须把关人同意）。

## 各级审查强度（速查）
| 项 | C0 | C1 | C2 | C3 |
|----|----|----|----|----|
| 门禁+语法 | ✔ | ✔ | ✔ | ✔ |
| 非作者主审 | — | 1 名 | 1 名 | ≥2 名（含安全视角） |
| 把关人 | — | 不必 | 必须 | 必须 |
| 通用+分层清单 | — | ✔ | ✔ | ✔ |
| 安全专项 | — | — | 触碰安全项时 | ✔ |
| 交互成对+矩阵更新 | — | — | 触碰文案/新入口时 | ✔ |
| UX 剧本走查 | — | — | 涉旅程 ≥1 | ≥2 |
| 回归 | 门禁 | run-tests 相关 | +verify-pairing | --full + verify-pairing + 契约 diff |
| 响应时限 | 免审 | ≤4h | ≤1 工作日 | ≤2 工作日 |

## 常见改动示例
| 改动 | 建议级 |
|------|--------|
| 改注释 / CSS 变量名 / 格式化 | C0 |
| 修复某函数校验漏判（1 文件） | C1 |
| 新增导出报表列 | C1~C2（触碰导出→C2 更稳） |
| 学生端新增一条 toast 或提示页 | **C2**（+2 文案） |
| 新增路由/SSE 事件/计时暂停逻辑 | C2 |
| 改 topics.js 物理主题/信封结构 | C3 |
| 改关机 HMAC 流程 | C3 |
