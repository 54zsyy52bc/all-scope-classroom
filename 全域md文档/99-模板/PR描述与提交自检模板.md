# PR 描述模板 + 提交前自检清单（按级裁剪）

> 依据 [[审查标准总纲_v2.0]] §8。复制使用。

## A. PR 描述模板

```markdown
## 变更摘要
<!-- 一句话：修了什么 / 加了什么 -->

## 改动分级（必填，先开速查卡判级）
- [ ] risk:C0（琐碎） ｜ risk:C1（常规） ｜ risk:C2（重要） ｜ risk:C3（高影响）
- 判定依据：评分卡得分 ____ ；是否命中一票升档 ____

## 关联
- 需求/缺陷：#issue ｜ 文档：[[关联文档]]
- 问题台账：[[已知问题与遗留项]]（如处理 L1/L2 等请注明）
- [hotfix] 事故链接（紧急修复必填）

## 变更内容
- [ ] 功能/修复描述（含行为变化）
- [ ] 涉及端：teacher / student / preset-studio / shared / 交付包
- [ ] 契约影响：topics.js / openapi.yaml / 信封（涉及则必走 C3）

## 测试
- [ ] 自动化：run-tests.sh（或 --full）结果
- [ ] 交互闭环：`node classroom-mgmt/scripts/verify-pairing.js`（C2+ 必填）
- [ ] UX 剧本走查（C2 涉旅程 / C3 必填）
- [ ] 手工验证步骤与风险/回滚

## 交互成对自查（触碰学生端文案/新入口时）
- [ ] 学生端提示 → 教师端对应可达完整入口？（矩阵 P#：____）
- [ ] 教师端操作 → 学生端可感知反馈？
- [ ] 术语查词表（总纲 §7.6）通过？
```

## B. 提交前自检清单（作者每次必做）

**判级与门禁**
- [ ] 填评分卡得 C0~C3；`risk:C*` 进 PR 标签
- [ ] 质量门禁（emoji/行数/硬编码色/按钮 ≥80px）；`node --check` 语法
- [ ] 无调试残留（console/debugger/TODO 已清理或注明）

**本仓库红线（违规即 🔴）**
- [ ] SQL 参数化 + 列白名单；禁止拼串
- [ ] 占位默认凭据（HMAC_SECRET / broker 口令）不上线
- [ ] 服务端兜底校验（座位/信封 type/状态枚举）
- [ ] 用户数据入 HTML/CSV/SQL 前净化（esc / 参数化 / 公式注入前缀）
- [ ] 共享契约只改 shared 单一真源
- [ ] 状态机迁移走 ALLOWED 表
- [ ] `catch(_e){}` 带注释
- [ ] 学生端新文案 → 教师端有闭环操作（交互成对）
- [ ] 控件可见阶段 = 服务端放行阶段

**质量**
- [ ] 核心行为 + 快乐/异常路径有测试
- [ ] diff 自读，注释与实现一致
