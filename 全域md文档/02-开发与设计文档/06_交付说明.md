## 一、系统组成（v4 分离式架构）

| 应用 | 位置 | 技术 | 职责 |
|------|------|------|------|
| **预设编辑器 Preset Studio** | `classroom-mgmt/preset-studio/` | Electron 44 + 本地 JSON 库 | **办公电脑独立应用**：班级/活动预设 CRUD、器材字典、计时默认配置、**预设包导出/导入**（.kctpreset）；零外部依赖、完全离线 |
| **教室教师端** | `classroom-mgmt/teacher/` | Node 22 + Express + better-sqlite3 + mqtt.js | 纯服务：聚合学生上行、HTTP+SSE 驱动大屏、活动/计时/策略、预设包**导入端点**、报表导出 |
| **大屏端** | 教师端服务 `/`（Web 页面） | 原生 HTML/CSS/JS（零构建） | 教室大屏：**预设导入（文件→预演→确认）/ 只读列表 / 删除卫生 / 导出备份** + 上课控制（选预设、活动发布、计时、锁定策略、SSE） |
| **学生机端** | `classroom-mgmt/student/` | Electron 44 + mqtt.js（WS） | 课前登记（器材随活动预设**动态下发**）/ 课中任务状态与计时显示 / 课后归还 / HMAC 校验关机（v4 零改动） |

共享契约 `classroom-mgmt/shared/`（topics.js / icons.js / **preset-package.js**）；SIoT2 broker 见 `SIoT_V2_Win_2618/`（workerNum=8 已修）。

## 二、部署三步（v4）

**1. 办公电脑装「预设编辑器」（Preset Studio）**——编辑预设的唯一入口
```bash
cd classroom-mgmt/preset-studio
npm install
npm start        # Electron 窗口：班级/活动预设 + 器材字典 + 导出/导入预设包
# 打包便携版分发：npm run pack → dist/PresetStudio.exe
```
数据存本机 `%APPDATA%/preset-studio/presets.json`（多台办公电脑各自维护，靠 .kctpreset 同步）。

**2. 教室教师机起服务 + 打开大屏**
```bash
cd classroom-mgmt/teacher
npm install
npm start        # http://0.0.0.0:3000，教室大屏浏览器打开 http://<教师机IP>:3000
```
预设传递：办公端「导出预设包」→ U盘/网盘带到教室 → 大屏「预设管理 → 导入预设包」→ **预演（新增/覆盖/跳过）→ 确认落库** → 上课/发布活动即用。

**3. 学生机**：每台学生机 `cd classroom-mgmt/student && npm install && npm start`（或 electron-builder 打包分发）。
部署前改两端 `app-config.json`：`siotIp`、`secret`（HMAC 两端一致）、学生端 `dryRun:false` 才真关机。
> 备注：Electron 二进制下载默认走 GitHub，网络受限时用镜像：`ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm install`。

## 三·五、预设包流转（v4：办公端 → 教室端）

- **文件格式 `.kctpreset`**（JSON）：`{pkg: 'kct-preset-package', schemaVersion, exportedAt, classes[], activities[]}`。
- **合并仲裁**：按 `presetId`（跨机器稳定）逐条比对 `updatedAt`——新增 / 覆盖（包内较新）/ **跳过**（本地较新，保护教室现场修改）。
- **导入两段式**：`POST /api/v1/presets/import`（预演，返回 added/updated/skipped + 明细）→ `?commit=true` 单事务落库。
- **反向**：大屏「导出备份」或 `GET /api/v1/presets/export` → 回办公端 Studio 导入继续编辑。
- 协议实现双端共享：`shared/preset-package.js`（校验/组包），教师端服务 `preset-pkg.service.js`，办公端 `store.commitImport` 同一套逻辑。

## 三·五·补、v4.2：备课增强（分组配置 / 上课器材 / 字典互通 / 单活动包）

- **分组配置**（班级预设）：每个小组可自定义组名与人数（`groups: [{groupId, size}]`）；UI「按分组大小均分生成」一键铺开；
  配置后座位数联动 = 各组之和（`total_seats` 服务端归一），开课时座位种子按自定义组播种（`db.seedSeatsByGroups`），小组墙显示组名。
- **上课器材**（班级预设）：`equipment` 随开课与活动器材**合并去重下发**（同 eqId 活动器材优先）；两者皆空才回退种子器材。
- **器材字典互通**：活动器材行与上课器材行「编号」输入联想器材字典（datalist 渲染，`preset-class-ui.js`）。
- **单活动预设包**：`exportPackage(filter)` 支持只导出指定活动/班级（活动列表「导出包」按钮），导入端不变（包即子集）。
- 大屏端与学生端零改动（classPresetId 链路自动带出）；数据模型：`t_class_preset` 增 `groups_json/equipment_json`（含旧库 migrate）。

## 三·六、v3：活动发布 / 计时 / 锁定策略（闭环联动）

- **活动发布**：大屏「发布活动」弹窗可选**预设活动**（一键带出器材/模板/默认计时）或**现场自定义**；发布时勾选「启用计时」+ 时长。
- **计时器**：教师端权威计时，学生端显示 mm:ss 倒数。控制：暂停 / 继续 / 调时长 / 重新计时 / 结束；
  **截止自动提醒师生双方**（大屏 SSE 弹截止条 + 学生端 toast/提示音）。学生端本地每秒递减，以广播校准。
- **锁定策略**：教师一键切换「全课可用 / 仅活动期间可用」。activity 模式下：登记/归还阶段不锁，
  task 阶段**有进行中活动才解锁**，活动截止/结束自动锁定学生机（全屏遮罩软锁，心跳保持）。
- 状态流转见 `07_功能联动与状态流转设计.md`。API：`/sessions/:sid/activities(/:taskId/timer)`、`/sessions/:sid/policy`。
- 协议：cmd `task`（带计时字段）/ `task_timer` / `policy`；sync 携带 currentTask 计时字段 + policy（迟到恢复）。

## 五、P0 规则门禁（已全量扫描通过）

- 无 emoji 图标（统一 Lucide SVG，`shared/icons.js` 唯一图标源）
- 无紫→粉渐变 / 发光边框 / 毛玻璃三件套
- 无硬编码颜色（全部 Design Token）
- 无 "Lorem ipsum" 等空洞占位（全部真实教学文案）
- 单文件常规 ≤ 300 行、db 仓储/存储后端 ≤ 320（大屏拆 app/presets/manage/stream；学生端拆 app/downlink/actions；Studio 拆 presets/preset-class-ui）
- 按钮触控目标 ≥ 80×80px；任一操作 ≤ 3 步

## 六、已知边界（非阻塞，如实说明）

| 项 | 说明 |
|----|------|
| 关机为 dry-run 默认 | `dryRun:true` 或 secret 为占位值时不真关机，需部署时显式放开 |
| Electron 下 better-sqlite3 | ABI 不匹配自动降级 JSON 存储（功能完整、数据持久）；要 SQLite 需 electron-rebuild |
| Preset Studio 数据 | 本地 JSON 文件（%APPDATA%），多台办公电脑各自维护；同步靠 .kctpreset 手动流转 |
| 器材字典为本地维护 | Studio 内置常用器材字典 + CRUD；与硬件实物清单需人工保持一致（eqId 编码约定） |
| 大屏视觉走查 | 无头测试已过逻辑层；真实浏览器观感建议部署后顺手过一眼 |
| 50 台并发 | **已压测达标**（2026-09-05，真实 broker，`test/stress.sim.js`）：登记 50/50≈600ms、P95 延迟 121ms、零掉线零错误；≥20 台真机仍建议开课前跑一次 1 分钟登记冒烟 |
| SIoT2 通配符 | 实测 `#` 可用、`+` 被拒；设计不依赖通配符（精确四主题） |
