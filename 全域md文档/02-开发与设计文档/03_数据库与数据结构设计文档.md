## 1. 数据存储策略
| 存储位置 | 用途 | 技术 | 说明 |
| --- | --- | --- | --- |
| 教师端本地 | 课堂数据持久化、导出 | SQLite（单文件 `classroom.db`） | 权威数据源 |
| SIoT2 服务端 | 消息中转（可选持久化） | 内置存储 | 仅通道，断线补发用 |
| 学生机本地 | 草稿/连接态缓存 | 本地文件/IndexedDB | 极小，重连补发用 |

> 设计原则：学生机不保存长期数据；所有登记、任务、器材记录在教师端落地，保证一致性与可导出的唯一来源。

## 2. 实体关系（ER）概要
```
Session(课堂会话) 1 ── * Student(学生登记)
Session(课堂会话) 1 ── * Task(任务)
Session(课堂会话) 1 ── * EquipmentBorrow(器材借还)
Student  * ── 1 Group(小组)            [以 group 字段表达]
Equipment 1 ── * EquipmentBorrow      [器材被多次借用]
Session 1 ── * EventLog(事件日志)
```
核心实体：Session、Student、Equipment、EquipmentBorrow、Task、TaskStatusFlow、EventLog。

## 3. 表结构（DDL 级设计）
> 下列为 SQLite 语法示意，字段类型按 SQLite 亲和性给出。

### 3.1 t_session 课堂会话
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| session_id | TEXT | PK | 会话UUID |
| teacher | TEXT | NOT NULL | 教师名/工号 |
| class_name | TEXT | | 班级 |
| start_time | INTEGER | | 上课时间戳(ms) |
| end_time | INTEGER | | 下课时间戳(ms) |
| phase | TEXT | | waiting/checkin/task/return/closed |
| total_seats | INTEGER | | 机房座位数(默认50) |
| export_flag | INTEGER | | 是否已导出 |

```sql
CREATE TABLE t_session (
  session_id  TEXT PRIMARY KEY,
  teacher     TEXT NOT NULL,
  class_name  TEXT,
  start_time  INTEGER,
  end_time    INTEGER,
  phase       TEXT DEFAULT 'waiting',
  total_seats INTEGER DEFAULT 50,
  export_flag INTEGER DEFAULT 0
);
```

### 3.2 t_student 学生登记
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| stu_id | TEXT | PK | seat 或 UUID |
| session_id | TEXT | FK→t_session | 所属课堂 |
| seat | TEXT | | 座位号 01–50 |
| group_id | TEXT | | 小组号 G1… |
| name | TEXT | | 姓名 |
| student_no | TEXT | | 学号 |
| checkin_time | INTEGER | | 登记时间 |
| checkin_status | TEXT | | pending/done |

```sql
CREATE TABLE t_student (
  stu_id       TEXT PRIMARY KEY,
  session_id   TEXT,
  seat         TEXT,
  group_id     TEXT,
  name         TEXT,
  student_no   TEXT,
  checkin_time INTEGER,
  checkin_status TEXT DEFAULT 'pending',
  FOREIGN KEY(session_id) REFERENCES t_session(session_id)
);
```

### 3.3 t_equipment 器材台账
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| eq_id | TEXT PK | 器材编号 |
| eq_name | TEXT | 名称(开发板/传感器/连线) |
| category | TEXT | 类别 |
| total | INTEGER | 库存总量 |

```sql
CREATE TABLE t_equipment (
  eq_id     TEXT PRIMARY KEY,
  eq_name   TEXT,
  category  TEXT,
  total     INTEGER DEFAULT 0
);
```

### 3.4 t_equipment_borrow 器材借还记录
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| borrow_id | TEXT PK | 记录UUID |
| session_id | TEXT FK | 课堂 |
| seat | TEXT | 借用座位 |
| group_id | TEXT | 小组 |
| eq_id | TEXT | 器材 |
| qty | INTEGER | 数量 |
| borrow_time | INTEGER | 领取时间 |
| return_time | INTEGER | 归还时间 |
| status | TEXT | borrowed/returned |

```sql
CREATE TABLE t_equipment_borrow (
  borrow_id   TEXT PRIMARY KEY,
  session_id  TEXT,
  seat        TEXT,
  group_id    TEXT,
  eq_id       TEXT,
  qty         INTEGER DEFAULT 1,
  borrow_time INTEGER,
  return_time INTEGER,
  status      TEXT DEFAULT 'borrowed',
  FOREIGN KEY(session_id) REFERENCES t_session(session_id)
);
```

### 3.5 t_task 任务
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| task_id | TEXT PK | 任务UUID |
| session_id | TEXT FK | 课堂 |
| title | TEXT | 任务名 |
| desc | TEXT | 说明 |
| publish_time | INTEGER | 发布时间 |
| close_time | INTEGER | 结束时间 |

```sql
CREATE TABLE t_task (
  task_id      TEXT PRIMARY KEY,
  session_id   TEXT,
  title        TEXT,
  desc         TEXT,
  publish_time INTEGER,
  close_time   INTEGER,
  FOREIGN KEY(session_id) REFERENCES t_session(session_id)
);
```

### 3.6 t_task_status 任务状态流水
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK AUTOINCREMENT | 自增 |
| task_id | TEXT FK | 任务 |
| seat | TEXT | 座位 |
| group_id | TEXT | 小组 |
| status | TEXT | doing/done/help |
| ts | INTEGER | 状态时间 |

```sql
CREATE TABLE t_task_status (
  id       INTEGER PRIMARY KEY AUTOINCREMENT,
  task_id  TEXT,
  seat     TEXT,
  group_id TEXT,
  status   TEXT,
  ts       INTEGER,
  FOREIGN KEY(task_id) REFERENCES t_task(task_id)
);
```

### 3.7 t_event_log 事件日志
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK AUTOINCREMENT | 自增 |
| session_id | TEXT | 课堂 |
| ts | INTEGER | 时间 |
| type | TEXT | checkin/task/return/cmd/shutdown/error |
| seat | TEXT | 相关座位 |
| detail | TEXT | 备注(JSON) |

```sql
CREATE TABLE t_event_log (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  session_id TEXT,
  ts         INTEGER,
  type       TEXT,
  seat       TEXT,
  detail     TEXT
);
```

## 4. MQTT 消息载荷（JSON）数据结构
与接口文档一致，下面给出权威结构。

### 4.1 登记 checkin（学生→教师）
```json
{
  "msgId": "uuid",
  "ts": 1693400000000,
  "type": "checkin",
  "seat": "07",
  "group": "G2",
  "payload": {
    "name": "张三",
    "studentNo": "20240007",
    "equipments": [
      {"eqId": "DEV-BOARD", "qty": 1},
      {"eqId": "SENSOR-T", "qty": 2}
    ]
  }
}
```

### 4.2 任务状态 task（学生→教师）
```json
{
  "msgId": "uuid", "ts": 1693400100000,
  "type": "task", "seat": "07", "group": "G2",
  "payload": { "taskId": "T-001", "status": "done" }
}
```
status ∈ {doing, done, help}

### 4.3 归还 return（学生→教师）
```json
{
  "msgId": "uuid", "ts": 1693400200000,
  "type": "return", "seat": "07", "group": "G2",
  "payload": { "allReturned": true, "note": "" }
}
```

### 4.4 指令 cmd（教师→学生，BROADCAST/cmd）
```json
{
  "msgId": "uuid", "ts": 1693400300000,
  "type": "cmd", "seat": "*", "group": "*",
  "payload": { "action": "start | end | task | shutdown | reset",
               "task": { "taskId":"T-001", "title":"点亮LED" } }
}
```

### 4.5 在线心跳 status（学生→教师，QoS0）
```json
{ "msgId":"uuid","ts":1693400400000,"type":"status",
  "seat":"07","group":"G2","payload":{"online":true} }
```

## 5. 数据保留与清理
- 单节课数据长期保留（学期内），供教学分析。
- 提供"导出后归档/删除历史"管理操作，按 session 删除级联（学生/借还/任务/日志）。
- SQLite 单文件便于备份与迁移。

## 6. 索引设计
```sql
CREATE INDEX idx_student_session ON t_student(session_id);
CREATE INDEX idx_borrow_session  ON t_equipment_borrow(session_id);
CREATE INDEX idx_taskstatus_task ON t_task_status(task_id);
CREATE INDEX idx_event_session   ON t_event_log(session_id);
CREATE INDEX idx_event_ts        ON t_event_log(ts);
```
