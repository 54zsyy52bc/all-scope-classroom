## 1. 接口总览
| 接口类别 | 载体 | 说明 |
| --- | --- | --- |
| MQTT 消息接口 | SIoT2/EasyIoT | 系统核心，学生机↔教师端实时通信 |
| 数据导出接口 | 教师端本地 | 生成 xlsx / csv 报表文件 |
| 系统关机接口 | 学生机 OS | 接收 shutdown 指令调用操作系统关机 |
| 内部模块接口 | 进程内 | 连接管理/聚合引擎/渲染间调用（不对外） |

> 本文档重点定义 MQTT 接口与导出/关机接口；内部模块接口仅给函数签名约定。

## 2. MQTT 核心接口

### 2.1 连接参数
| 参数 | 值 |
| --- | --- |
| broker | tcp://<SIoT2_IP>:1883 |
| clientId | `STU_{seat}`（学生机）/ `TEACHER`（教师端） |
| username / password | SIoT2 账户（必填） |
| keepAlive | 30 s |
| cleanSession | false |
| QoS 默认 | 1（指令/业务），0（心跳） |

### 2.2 主题与方向总表
| 主题 | 发布者 | 订阅者 | QoS | 载荷 type |
| --- | --- | --- | --- | --- |
| `ICTClass/BROADCAST/cmd` | 教师 | 学生机 | 1 | cmd |
| `ICTClass/STU_{seat}/checkin` | 学生机 | 教师 | 1 | checkin |
| `ICTClass/STU_{seat}/task` | 学生机 | 教师 | 1 | task |
| `ICTClass/STU_{seat}/return` | 学生机 | 教师 | 1 | return |
| `ICTClass/STU_{seat}/status` | 学生机 | 教师 | 0 | status |

### 2.3 消息通用信封
```json
{
  "msgId": "字符串,UUID",
  "ts": "整数,Unix毫秒",
  "type": "checkin|task|return|cmd|status",
  "seat": "座位号(学生) | '*' (广播)",
  "group": "小组号 | '*'",
  "payload": { }
}
```

### 2.4 接口 I-CMD-01 教师广播指令
- 主题：`ICTClass/BROADCAST/cmd`
- 方向：教师 → 学生机
- QoS：1
- 动作枚举：
  | action | 含义 | 触发 |
  | --- | --- | --- |
  | start | 开始上课，进入登记 | 教师点「开始上课」 |
  | end | 下课，进入归还 | 教师点「下课」 |
  | task | 发布/切换任务 | 教师点「发布任务」 |
  | shutdown | 全员关机 | 全部归还确认后自动/教师强制 |
  | reset | 重置本机登记 | 教师代操作 |
- 载荷示例：
```json
{"msgId":"c1","ts":1693400300000,"type":"cmd","seat":"*","group":"*",
 "payload":{"action":"task","task":{"taskId":"T-001","title":"点亮LED","desc":""}}}
```

### 2.5 接口 I-CHK-01 学生登记上报
- 主题：`ICTClass/STU_{seat}/checkin`
- 方向：学生机 → 教师
- QoS：1
- 校验：name/studentNo/equipments 必填；重复 msgId 幂等。

### 2.6 接口 I-TSK-01 任务状态上报
- 主题：`ICTClass/STU_{seat}/task`
- 方向：学生机 → 教师
- QoS：1
- status ∈ {doing, done, help}；done/help 触发大屏高亮。

### 2.7 接口 I-RET-01 归还确认上报
- 主题：`ICTClass/STU_{seat}/return`
- 方向：学生机 → 教师
- QoS：1
- allReturned=true 时该组计入"已归还"。

### 2.8 接口 I-STA-01 在线心跳
- 主题：`ICTClass/STU_{seat}/status`
- 方向：学生机 → 教师
- QoS：0
- 频率：每 15s 一次；用于大屏在线计数与掉线提示。

## 3. 数据导出接口

### 3.1 导出请求（教师端内部调用）
```
exportReports(sessionId, formats=[xlsx|csv], scope=current|history)
```
- 输出文件：
  - `登记表_{sessionId}.xlsx/csv` ← t_student
  - `任务记录_{sessionId}.xlsx/csv` ← t_task + t_task_status
  - `器材使用_{sessionId}.xlsx/csv` ← t_equipment_borrow + t_equipment
  - `事件日志_{sessionId}.xlsx/csv` ← t_event_log

### 3.2 字段映射（登记表）
| 列 | 来源 |
| --- | --- |
| 座位 | t_student.seat |
| 小组 | t_student.group_id |
| 姓名 | t_student.name |
| 学号 | t_student.student_no |
| 登记时间 | t_student.checkin_time |
| 领取器材 | 聚合 t_equipment_borrow(qty×eq_name) |

### 3.3 格式要求
- xlsx：SheetJS 生成，含表头样式、多 Sheet。
- csv：UTF-8 with BOM（Excel 中文不乱码），逗号分隔。

## 4. 系统关机接口

### 4.1 触发条件
- 教师端判定"全部小组 allReturned=true" → 自动下发 `cmd:shutdown`；
- 或教师点「强制关机」。

### 4.2 学生机执行约定
```
onReceive(cmd.shutdown):
    if OS == Windows:  call "shutdown /s /t 10"
    if OS == Linux:    call "shutdown -h +0"
    延迟 10s 以便提示用户保存
```
- 关机前弹窗提示"即将关机，请保存"，10 秒后执行。
- 仅在 `end` 阶段（课后）允许执行关机，避免误触。

## 5. 错误码与异常处理
| 错误码 | 含义 | 处理 |
| --- | --- | --- |
| E-CONN-01 | 无法连接 SIoT2 | 显示离线，启动重连 |
| E-AUTH-01 | 认证失败 | 提示检查账号/配置 |
| E-DUP-01 | 重复 msgId | 幂等忽略 |
| E-VAL-01 | 载荷校验失败 | 拒绝并记录日志 |
| E-OFF-01 | 非上课态收到登记 | 忽略或缓存待关联 |

### 5.1 重连补偿
- 断线期间关键操作（checkin/task/return）入本地队列；
- 重连成功后按 ts 顺序补发，教师端依 msgId 去重。

## 6. 报文样例（端到端）
```
[教师] 发布 start
-> ICTClass/BROADCAST/cmd
   {"msgId":"c0","ts":T,"type":"cmd","seat":"*","group":"*",
    "payload":{"action":"start"}}

[学生07] 登记
-> ICTClass/STU_07/checkin
   {"msgId":"m1","ts":T+5,"type":"checkin","seat":"07","group":"G2",
    "payload":{"name":"张三","studentNo":"20240007",
               "equipments":[{"eqId":"DEV-BOARD","qty":1}]}}

[学生07] 求助
-> ICTClass/STU_07/task
   {"msgId":"m2","ts":T+120,"type":"task","seat":"07","group":"G2",
    "payload":{"taskId":"T-001","status":"help"}}

[教师] 全部归还后关机
-> ICTClass/BROADCAST/cmd
   {"msgId":"c9","ts":T+600,"type":"cmd","seat":"*","group":"*",
    "payload":{"action":"shutdown"}}
```
