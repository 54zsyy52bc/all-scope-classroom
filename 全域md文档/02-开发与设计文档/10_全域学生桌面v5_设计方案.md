# 10 · 全域学生桌面 v5（组机登记 + 上课桌面）设计方案

> 日期：2026-09-08 ｜ 目标交付：2026-09-10（教师节）v5 可用版
> 场景：机房 **12–16 台电脑，每组共用一台**。开机后学生进入「全域」上课桌面，按组登记上课。

---

## 一、终端与数据模型（不推翻 seat，做“终端化”）

| 概念 | v4.5（一人一机） | v5（组机） |
|------|------------------|-----------|
| 终端 | 座位=机器 | **机器 = 组终端**（T01..T14） |
| 槽位 | seat 01..50 全局唯一 | **组内序号 seat 01..K**（K=每组容量，如 6） |
| 登记 | 一人填一次 | **组长先登记（组号+组长姓名）→ 成员按组内序号依次登记** |
| 大屏 | 50 座网格 | **组终端卡片 ×14**，卡片内列成员 |

落地策略：
- **保留现有 seat 槽位与全部上行/下行协议**（seats 01..K per 终端 ⇒ 仍为 01..84 全局槽位，只是按组连续）——db/service/测试改动收敛。
- teacher 配置由 `50 座`改为 `终端台数 T × 每端容量 K`（如 14×6=84 槽），大屏渲染加"按组聚合终端卡"模式。
- student 端登记体验重写为组流程：选本机终端（自动识别，machineId 预绑定 seat 段）→ 组长输入组号+姓名 → 后续成员点"下一位"在下一槽登记。

## 二、v5 三端职责

```
┌─ 教师大屏（teacher，改）────────────────────────────┐
│ 终端卡 ×14（每卡=组内成员列表/状态） │ 活动/归还/关机 │ 课程配置+口令 │
└──────────────────────────────────────────────────┘
┌─ 全域学生桌面（student-shell，新 Electron）────────────┐
│ ① 开机模式选择（上课 / 自由创作，口令可配）            │
│ ② 上课 → 课程选择（老师下发的课程列表）                │
│ ③ 进入课程桌面 = 全域 UI（组登记 → 任务 → 归还）      │
│ ④ 右上角齿轮（系统设置，口令≠课程密码≠模式口令）       │
│ ⑤ 状态顶栏：机器编号 / 组号 / 防护状态（kiosk 常驻）   │
└──────────────────────────────────────────────────┘
┌─ Preset Studio（改）：课程预设（课程+口令+桌面白名单）──┐
```

## 三、口令体系（四套独立）

| 口令 | 用途 | 谁能设 | 约束 |
|------|------|--------|------|
| 模式口令（可选） | 切「自由创作」需验证 | 教师 | 为空=无需口令 |
| 课程密码 | 学生进入/切换课程需验证 | 教师（每课程） | 与系统口令互异 |
| 系统口令（齿轮） | 设置/退出上课桌面 | 教师 | ≠课程密码 |
| （组号校验） | 组长登记组号合法性 | 教师预置组名 | — |

口令仅存哈希（SHA-256+salt），服务端统一管理，任何口令都不同库；客户端不存明文。输入错误 3 次锁 60s 防爆破。

## 四、两种模式权限差异 + 防绕过（应用层）

| 能力 | 上课模式 | 自由创作模式 |
|------|---------|--------------|
| 应用 | 仅课程白名单 | Windows 正常 |
| 文件 | 仅课程共享目录/教学盘 | 全部 |
| 上网/外设 | 按课程策略 | 系统默认 |
| 退出到模式选择 | 需系统口令 | 开机界面可回 |

防绕过（Electron kiosk + 守卫，覆盖课堂 99%）：
1. 全屏无边框 + `disableFrame` + 常驻置顶 + `kiosk`
2. 拦截 F11/Alt+F4/Esc/任务栏；注册进程守卫：发现 explorer.exe/任务管理器被调起即收回焦点并告警
3. `setKiosk` + 窗口关闭前强制校验口令
4. 开机自启（Run 键值）+ 自崩溃重启（看门狗双进程）
5. 防 U 盘引导/BIOS 绕过 = 明确列为**不做**（需系统层策略，交付说明中明示边界）

## 六、范围与风险（诚实清单）

- 测试改造面大：原 50 座断言（dashboard 34 / smoke 77 / stress）部分改为组终端语义——用"T×K 槽位"兼容保留绝大多数。
- 桌面壳 Electron 需新打包（win-unpacked ~180MB）。
- **应用层防绕过的极限**会在手册里写清楚（无法对抗物理手段），教学场景足够。
- 若 9/10 未达 14/14 全绿，交付预案 = v4.5（tag v4.2-deliverable 已备）+ v5 演示包。
