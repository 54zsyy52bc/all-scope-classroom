## 阅读顺序建议
1. 先读 **01 需求**：明确"做什么"与约束（≤3 步、50 台并发、断线重连）。
2. 再读 **02 架构**：理解"怎么连"（SIoT2 主题与通信机制）。
3. 并行参考 **03 数据 / 04 接口 / 05 界面**：开发时按模块取用。

## 关键设计约定（跨文档一致）
- **项目/主题前缀**：`ICTClass`（可配置）。
- **学生主题**：`ICTClass/STU_{seat}/{checkin|task|return|status}`，QoS 1（status 为 0）。
- **教师广播**：`ICTClass/BROADCAST/cmd`，QoS 1。
- **消息信封**：`{msgId, ts, type, seat, group, payload}`。
- **阶段状态机**：waiting → checkin → task → return → closed。
- **权威数据**：教师端 SQLite（`classroom.db`）；SIoT2 仅做通道。
- **关机触发**：全部小组 `return.allReturned=true` 后自动下发 `cmd:shutdown`。
