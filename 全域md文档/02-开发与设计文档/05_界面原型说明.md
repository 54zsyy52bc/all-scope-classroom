## 1. 设计原则
- **三步内完成**：打开→填写/点按→确认，每屏仅一个核心目标。
- **大按钮 + 状态色**：主操作按钮 ≥ 80×80px，色块传达状态，降低文字依赖。
- **常驻连接指示**：右上角显示「已连接 / 重连中 / 离线」。
- **阶段自适应**：界面随课堂阶段（登记/任务/归还）自动切换，学生无需导航。

## 2. 学生机操作界面

### 2.1 界面 A：课前登记（阶段=checkin）
```
┌──────────────────────────────────────────────┐
│  信息技术实践课             ●已连接   座位:07   │  ← 顶栏：连接态+座位
├──────────────────────────────────────────────┤
│                                                │
│       请登记你的信息（第 1/1 步）              │
│                                                │
│   姓名: [ 张三__________ ]                      │
│   学号: [ 20240007______ ]                      │
│   小组: (●G2) ( G1) ( G3) ( G4)                │
│                                                │
│   本组领取器材:                                 │
│   [✓] 开发板 ×1   [✓] 温度传感器 ×2            │
│   [ ] 杜邦线 ×10  [ ] 电池盒 ×1                 │
│                                                │
│              ┌──────────────┐                  │
│              │   确认登记    │  ← 主按钮(大)    │
│              └──────────────┘                  │
└──────────────────────────────────────────────┘
```
元素清单：
- 顶栏：连接指示灯、座位号（自动识别）。
- 输入：姓名、学号（管理员预填时可只读核对）。
- 小组：单选大圆点。
- 器材：复选 + 数量，与实际台账一致。
- 主按钮：`确认登记`（提交即上报 checkin）。
- 提交后本屏锁定为"已登记 ✓"，仅显示状态。

### 2.2 界面 B：课中任务（阶段=task）
```
┌──────────────────────────────────────────────┐
│  当前任务: 点亮LED        ●已连接   座位:07    │
├──────────────────────────────────────────────┤
│                                                │
│   任务说明: 用开发板让板载LED闪烁               │
│                                                │
│   ┌────────┐   ┌────────┐   ┌────────┐        │
│   │ 进行中 │   │ 已完成 │   │  求助  │  ← 三选一 │
│   └────────┘   └────────┘   └────────┘        │
│                                                │
│   状态: 已完成 ✓  (已上报, 可改)               │
└──────────────────────────────────────────────┘
```
元素清单：
- 任务卡：标题 + 说明（教师发布）。
- 三个大状态按钮：点按即上报 task(status)，单次操作。
- 允许切换状态（如 done→help），每次切换均上报。

### 2.3 界面 C：课后归还（阶段=return）
```
┌──────────────────────────────────────────────┐
│  下课 · 请归还器材        ●已连接   座位:07    │
├──────────────────────────────────────────────┤
│                                                │
│   请对照实物清点并勾选:                        │
│   [✓] 开发板 ×1   [✓] 温度传感器 ×2           │
│   [✓] 杜邦线 ×10  [✓] 电池盒 ×1               │
│                                                │
│              ┌──────────────┐                  │
│              │  确认归还     │  ← 主按钮(大)   │
│              └──────────────┘                  │
│        (全部小组确认后本机将自动关机)           │
└──────────────────────────────────────────────┘
```
元素清单：
- 归还清单（默认带出领取清单，便于核对）。
- 主按钮：`确认归还`（上报 return, allReturned=true）。
- 底部提示关机逻辑，降低焦虑。

### 2.4 学生机连接态约定
| 状态 | 指示 | 行为 |
| --- | --- | --- |
| 已连接 | 绿点"已连接" | 正常可操作 |
| 重连中 | 黄点"重连中" | 操作入本地队列，禁用提交按钮 |
| 离线 | 红点"离线" | 提示联系教师，队列待补发 |

## 3. 教师端大屏看板

### 3.1 总体布局
```
┌──────────────────────────────────────────────────────────────┐
│ 课堂看板 | 初二(3)班 信息技术      上课 09:00  在线 48/50  ●已连接│  ← 顶栏
├──────────────────────────────────────┬───────────────────────┤
│  小组进度矩阵 (主区)                  │  实时事件流 (右栏)     │
│  ┌────┐┌────┐┌────┐┌────┐           │ 09:01 07组 已登记     │
│  │G1  ││G2*││G3  ││G4  │  ← *求助闪烁│ 09:02 12组 已完成    │
│  │done││help││do  ││wt  │           │ 09:03 07组 求助LED    │
│  └────┘└────┘└────┘└────┘           │ ...                   │
│  ┌────┐┌────┐ ... (按座位/组排布)    │                       │
│                                       │  器材统计:            │
│  到课: 48/50   未登记: 02,09          │  开发板 领48/还30      │
│  器材领取率: 96%                      │  传感器 领96/还60      │
├──────────────────────────────────────┴───────────────────────┤
│ [开始上课]  [发布任务]  [下课]  [导出报表]  [提醒未确认] [强制关机]│  ← 底部控制栏
└──────────────────────────────────────────────────────────────┘
```

### 3.2 区域说明
| 区域 | 内容 | 数据来源 |
| --- | --- | --- |
| 顶栏 | 班级、上课时间、在线数、连接态 | session + status 心跳 |
| 主区·小组矩阵 | 每组/座位色块显示状态 | checkin/task/return 聚合 |
| 主区·统计卡 | 到课率、未登记名单、器材领取率 | 聚合计算 |
| 右栏·事件流 | 滚动显示最新上报（时间+座位+动作） | t_event_log |
| 右栏·器材统计 | 各器材领/还数量 | t_equipment_borrow |
| 底部控制栏 | 上课/任务/下课/导出/提醒/强制关机 | 指令发布器 |

### 3.3 状态色彩规范
| 状态 | 颜色 | 含义 |
| --- | --- | --- |
| 未开始/等待(waiting) | 灰 | 未登记或未开始 |
| 进行中(doing) | 蓝 | 任务进行中 |
| 已完成(done) | 绿 | 已完成/已登记/已归还 |
| 求助(help) | 橙红 + 闪烁 | 需教师指导，置顶提示 |
| 离线(offline) | 红边 | 该机掉线 |
| 连接正常 | 绿点 | 通信正常 |

## 4. 布局与适配
- 学生机：适配机房常见分辨率（1366×768 / 1920×1080），纵向单列，触控/鼠标均可。
- 教师大屏：≥1920×1080，横向三区（主区+右栏+控制栏），投影清晰。
- 字体：界面正文 ≥ 18pt，按钮文字 ≥ 20pt，保证后排可见。

## 5. 交互步数核对（对照需求 NFR-U1）
| 操作 | 步数 |
| --- | --- |
| 学生登记提交 | 填写→确认 = 2 步 |
| 学生反馈"已完成" | 点按钮 = 1 步 |
| 学生确认归还 | 勾选→确认 = 2 步 |
| 教师开始上课 | 点「开始上课」= 1 步 |
| 教师发布任务 | 点「发布任务」= 1 步（说明可选） |
| 教师导出报表 | 点「导出」→选格式 = 2 步 |
| 教师强制关机 | 点「强制关机」= 1 步 |
> 全部 ≤ 3 步，满足约束。
