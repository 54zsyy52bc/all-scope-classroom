# 9/10 教师节现场 · 全域课堂 v5 准备与演练清单

> 时间参考：教师节当天课前 30 分钟布置。异常排查→看末尾《常见问题》。

## 一、硬件与启动顺序

1. **教师机**：电源/大屏 → 启动 → 双击运行 `2_教师机\启动服务.bat`（若有；否则终端进 `2_教师机/teacher` 执行 `node server.js`）→ 等控制台出现 `teacher server 就绪`。
2. 浏览器打开教师大屏：`http://127.0.0.1:3000`（或局域网 IP）。
3. **学生机 × N 台**：各自双击 `3_学生端\StudentClient.exe` → 应出现「全域」模式选择屏。

> 若某台学生机要调试（不锁屏）：`StudentClient.exe --no-kiosk`。
> 14 台=每组一台时，开课表单填「终端台数=台数、每组人数=本组最多人数」。

## 二、学生机一次性配置（老师逐台约 1 分钟/台）

学生机开「设置」→ 需管理员口令（首次默认无口令，直接进入）→ 填写：

- **课程名称**：如 `信息技术·硬件实践课`
- **应用白名单**（每行 `显示名|exe`，如需要）：
  ```
  画图|mspaint.exe
  记事本|notepad.exe
  ```
- **禁用进程**：`chrome.exe,msedge.exe,firefox.exe`（默认已填）
- **勾「启用禁用进程强杀」**
- 口令（**建议启用**，两口令必须互不相同，各 4-32 位）：
  - 「自由创作口令启用」+ 新口令，如 `qy2026`
  - 「管理员口令启用」+ 新口令，如 `qyAdmin2026`（≠ 自由创作口令）
- 点「保存本机桌面配置」→ 绿字提示即成功

> 保存即本机生效，**重启学生端**后进课堂生效。

## 三、开课流程（教师大屏）

1. 大屏右上点「开始上课」→ 填教师姓名/班级 → **终端台数 × 每组人数**（如 14×6=84）→ 开始上课。
2. 大屏出现「终端 01…终端 14」卡片。
3. 学生机：全域首屏 → 「上课模式」→ 选课程 → 进入课堂。
4. **组长登记**（勾选「我是本组组长」，座位号填 01）→ 其余成员按 02、03… 依次登记。
5. 大屏对应终端卡点亮、组长带蓝色「组长」角标。
6. 活动/任务/归还/关机与 v4 一致。

## 四、必验清单（5 分钟快速过）

- [ ] 学生机开机自动进全域桌面（不是进 Windows）
- [ ] 开「设置」要管理员口令；口令输错 3 次锁 30 秒
- [ ] 「自由创作」需自由创作口令 → 验证通过退出到系统桌面
- [ ] 课堂内学生开 chrome（被禁）→ 3 秒内被杀 + 红字「已阻止应用」
- [ ] 白名单应用（画图）可从课堂顶部磁贴正常打开
- [ ] 大屏：终端卡人数/组长/状态正确、活动计时与锁定正常
- [ ] 归还全部器材后学生机自动关机（演练模式会走 dry-run 倒计时）

## 五、日志（出问题第一时间发这些）

- 学生机：`%APPDATA%\课堂学生端\audit.log`（含 boot/shell/上下行/保存操作）
- 教师机：`2_教师机\teacher\logs\audit.log`（含全部写请求 + 大屏 GUI 事件）

## 六、常见问题速查

| 现象 | 处理 |
|------|------|
| 学生机双击没反应 | 先杀旧进程（任务管理器结束 StudentClient）再开；用 `--no-kiosk` 看报错 |
| 保存配置红字 | 两口令相同/未设新口令就勾启用/口令位数错 → 按红字改正 |
| 忘了管理员口令 | 关学生端，删除 `resources\app\app-config.json` 里整个 `"shell": {...}` 段（或整文件备份后删 shell 段）→ 重启即免口令 |
| 学生机没进全域桌面进了系统 | 设置里「开机自启」关了 → 齿轮打开勾回（或重启后手动开 StudentClient） |
| 学生课堂内发现浏览器还能开 | 「禁用进程强杀」没启用 → 设置勾上保存并重启 |
| 大屏没服务/连接中 | 教师机 `node server.js` 是否在跑、浏览器 F5 |
